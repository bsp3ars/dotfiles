# NVM - Node Version Manager

## Main Repository

> You should use the installation steps provided on the README.md

https://github.com/nvm-sh/nvm

## Useful Commands

```bash
# See the latest Node.js LTS release
nvm list-remote --lts

# Install the latest LTS release
nvm install --lts

# Set the latest LTS release as the default (performed by default with the first install)
nvm alias default VERSION

# Verify the current Node.js version
nvm current

# Install Angular CLI globally
npm install -g @angular/cli@VERSION

# Disable Angular analytics
ng analytics off --global
```
